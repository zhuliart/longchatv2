## T7.3 核心链路 E2E（`cd web && npm run test:e2e`；`--list` 已校验 5/5）

`web/playwright.config.js` + `web/tests/e2e/`（移动版式，Chromium 走预装路径不联网下载）：

1. **注册 → 3 步引导 → 首页**（真实表单闭环）。
2. **记心情 → 月历/趋势可见 → 改可见性为公开 → 他账号在广场看到 → 评论**（含登出/登录切换）。
3. **看推荐 → 对方主页 → 写首封(≥150) → 对方登录拆信（动画）→ 回信(≥100) → 发起方收到**。
4. **草稿保存 → 草稿箱恢复 → 补足字数寄出 → 服务端删草稿（草稿箱清零）**。
5. **AI 续写**：配置密钥时点击候选插入正文并断言正文增长；未配置时断言 9002 优雅降级提示
   （两条路径均不崩溃）。

`tests/e2e/global-setup.js` 先探活 `:3000/api/v1/health`，未就绪即给出「起 Mongo→seed→起后端」
的明确指引并中止，避免把环境未就绪误判为用例失败。

**本地实跑步骤**：
```bash
docker compose -f deploy/docker-compose.dev.yml up -d      # MongoDB
cd server && npm run seed && npm run dev                     # 后端 :3000
cd web && npm run test:e2e                                   # 前端由 playwright 自动拉起
```

## T7.4 兼容与响应式（静态自查通过）

- **断点**：`useIsDesktop` 以 `768px` 分移动/桌面；`desktop.css` 含 `1180 / 1160 / 960` 三档

## T7.5 安全自查（静态自查通过）

- **密钥不入前端产物**：`grep dist/` 无 `JWT_SECRET / *_API_KEY / ALI_GREEN_AK / sk-ant- / MONGO_URI /
  password_hash`（AI/审核密钥仅在服务端环境变量）。
- **XSS**：全站无 `dangerouslySetInnerHTML`，信件正文/日记/评论均按纯文本渲染。
- **CORS**：`app.use(cors({ origin: config.corsOrigin }))` 白名单；叠加 `helmet()`。
- **NoSQL 注入**：路由入参统一 `String()` 强转 + `asObjectId` 校验 + 枚举白名单（情绪/可见性/时段/
  频率），查询操作符（`$gt` 等）无法经请求体注入。
- **鉴权健壮性**：JWT 篡改/过期→401（`auth.test.js` 覆盖）；登录 IP + 账号双维度限速；
  refresh 轮换 + 黑名单（TTL 自动清理）。
- 生产上线项（HTTPS 强跳、3000/27017 不对公网、`.env.production` 权限 600）属 M8，见附录 C。
