# 云资源采购与 ICP 备案清单（T0.7 · 人工操作项）

> ⚠️ 本清单为**必须由账号所有人人工完成**的操作（涉及实名认证、付款、备案材料）。
> **备案是上线关键路径（通常 1–3 周），请立即发起**；备案期间开发联调可用 ECS 公网 IP 进行，不受影响。

## 1. 域名（立即）

- [ ] 在阿里云万网选购域名（建议 `.com` / `.cn`；`.cn` 备案材料略多但更稳）
- [ ] 域名实名认证（备案前置条件，实名信息须与备案主体一致）

## 2. ICP 备案（立即发起，周期 1–3 周）

- [ ] 阿里云控制台 →「ICP 备案」发起新增备案（备案必须绑定一台阿里云中国内地服务器）
- [ ] 准备材料：主体证件（个人身份证 / 企业营业执照）、负责人手机号 + 人脸核验、网站名称与服务内容描述
  - 网站描述建议：「书信交流与情绪记录的个人成长类网站」；**避免出现"社交/交友"字样**（社交类可能被要求前置审批，个人主体尤其注意）
- [ ] 初审（阿里云 1–2 个工作日）→ 管局审核（各省 5–20 个工作日）
- [ ] 通过后：备案号挂到网站页脚（M8 检查项）；30 日内完成**公安联网备案**（beian.gov.cn）

## 3. ECS（立即，备案需绑定）

- [ ] 规格：2 vCPU / 4 GB / 40 GB ESSD，**Ubuntu 22.04 LTS**；地域选目标用户近的内地节点（如华东1-杭州/华东2-上海）
- [ ] 计费：包年包月（备案要求实例剩余时长 ≥3 个月，按量付费实例不可备案）
- [ ] 安全组初始规则：仅放行 22（限办公 IP）/ 80 / 443；**3000、27017 一律不开放公网**
- [ ] 设置 SSH 密钥对登录，记录公网 IP 供联调

## 4. SSL 证书（备案通过后）

- [ ] 阿里云「数字证书管理服务」申请**免费 DV 证书**（个人版每年可申领多张，单张有效期 3 个月需按期轮换；或改用 certbot 自动续期）

## 5. 内容安全（M4 前开通）

- [ ] 开通「内容安全」→ 文本审核增强版（按量付费）
- [ ] RAM 创建子账号，仅授予 `AliyunYundunGreenWebFullAccess`（最小权限），生成 AK 填入 `deploy/.env.production` 的 `ALI_GREEN_AK_ID/SECRET`

## 6. AI 灵感 — 百炼 DashScope（M4 前开通）

- [ ] 开通「阿里云百炼」，创建 API Key → `DASHSCOPE_API_KEY`
- [ ] 模型建议 `qwen-plus`（质量/成本均衡），并在控制台设置消费限额告警

## 7. OSS 备份桶（M8 前）

- [ ] 创建 Bucket（低频访问型，与 ECS 同地域走内网）；开启版本控制或设置 14 天生命周期规则
- [ ] RAM 子账号仅授予该 Bucket 的写权限，AK 供备份脚本使用

## 8. 云监控（M8 前）

- [ ] 开通云监控（免费额度足够），配置告警联系人（短信/钉钉）
- [ ] 告警项：CPU >80%、磁盘 >85%、站点监控探测 `https://域名/api/v1/health`
